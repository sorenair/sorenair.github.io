# Portfolio Redesign Agent Assignments

Use the [redesign brief](PORTFOLIO_REDESIGN_BRIEF.md) for design and content decisions and the [development plan](PORTFOLIO_DEVELOPMENT_PLAN.md) for integration and release checks.

## Agent 1 Site foundation and integration

- Own the static build, GitHub Pages configuration, route map, shared navigation and footer, and responsive page shell.
- Define the shared visual system for the Ø identity, typography, color, spacing, focus states, and motion. Own changes to shared components and styles.
- First deliverable is a working site shell and a route map that Agents 2 and 3 can build against. Lead final integration and verify the GitHub Pages build.

## Agent 2 Home, About, and Contact

- Own the homepage, hero media, and homepage motion. Explore a video-led opening and a project-led opening with a clear route into Work.
- Build About from the existing public content with a directly addressable Contact section at `/about/#contact`. Coordinate the footer link and legacy contact URL with Agent 1.
- First deliverable is both opening studies at phone and desktop sizes, including how the video or still frame behaves.

## Agent 3 Work and project library

- Own the Work page, Technical and Creative views, project cards, project content template, individual project URLs, and motion between the library and project details.
- Define the project fields and share them with Agent 2 for homepage previews. Document how to add a project using the template and its media files.
- First deliverable is a library with PØRTAL, WiFi Transceiver, and ØVERCLOCK, plus a complete PØRTAL page. Returning from the detail page should restore the visitor’s category and browsing position, with focus returned to the card when appropriate.

## Handoffs and first integration milestone

1. Start the three workstreams in parallel. Agent 1 publishes the route map and shared styles, Agent 3 publishes the project fields, and Agent 2 explores the hero using the existing footage and imagery.
2. Each agent edits the files for their area. Coordinate shared changes through Agent 1. Agents 2 and 3 implement motion within their pages using the shared motion guidance.
3. Review **Home → Work → PØRTAL → Back** on desktop and a phone before migrating the rest of the content. Check that the work is easy to reach and that the return flow works with touch, keyboard, and reduced-motion settings.
